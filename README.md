A mod that aims to port The Watcher from Slay the Spire 1 to Slay the Spire 2, but i a way that is designed to make her feel like a natural part of STS2's ecosystem.

Full card effects + Changelog: https://docs.google.com/spreadsheets/d/1a5RIFOfQ--Bagtl7E11VCqbMfHOES77KaBaTj10vF6Y

Steam Workshop page: https://steamcommunity.com/sharedfiles/filedetails/?id=3793048512


This project is NOT A TEMPLATE and is not intended to be used as a base for creating your own mods.

If you need a template use this https://github.com/Alchyr/ModTemplate-StS2/wiki/Setup

Reusing this project directly (e.g. copying it and modifying it into your own mod) will very likely:
-break compatibility with this mods.
-cause ID conflicts
-introduce hard-to-debug issues
-create maintenance problems across updates
-It would also be unfair to the modding ecosystem if multiple incompatible mods were built directly on top of this project.

Feel free to use code from this mod in anyway you like but most of it for patching the Base Watcher mod by Lamali so I would say isn't that useful
